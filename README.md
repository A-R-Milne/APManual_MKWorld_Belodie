# Mario Kart World Manual (Bélodie's Implementation)

I initially built this as a slight edit of [MaudeTheMegaMawile's Version](https://discord.com/channels/1097532591650910289/1508530338354429983) that I could use in syncs, but I've changed it so much that at this point, this is a variant in its own right. Thank you to Maude for making the initial version.

Outside of cups and rallies, you are expected to use VS Mode, with custom items on.

## Locations
- Winning and getting top 3 at each track, with separate checks for non-route/intermission versions and routes/intermissions involving the tracks
- Winning at each track using a certain character
- Winning using a specific vehicle and a character/costume that uses it when driven by a CPU
- Rallies (getting to a checkpoint first for each CC, completing for each CC and reaching each checkpoint)
- Cups (getting 1st in each race, and winning and getting top 3 in the cup as a whole for each CC)
- Winning at 1, 2, 3, 4, 5, 6, 7, 8, 10, 12, 14 and 16 unique tracks.

## Items
- Tracks
- Characters
- Vehicles
- Items (and the ability to ignore some more annoying ones)
- The ability to trick in each direction, drift and charge jump (blue, orange and rainbow), use rail grinding, water riding, gliding, wall riding and rewinding
- Reducing the amount of tracks you need unlocked to play a cup or a rally
- Trophies for each cup (Rainbow Road is unlocked by obtaining one of each, except Special Cup)
- Rally trophies (primarily filler items; 1 is needed to do Rallies 9+)
- Rainbow Fragments (McGuffin hunt items)

## Go Mode Requirements
- Acorn Heights, Mario Circuit, Peach Stadium and Rainbow Road [which in turn requires one of each non-rally trophy except Special Cup]
- Wings (for gliding), Water Skis (for driving over water) and Rail-Safe Tyres (for rail grinding)
- 16 Rainbow Fragments
